# Student Score Prediction

This project predicts student scores based on study hours using **Linear Regression**.

## Tools Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Project Features

* Dataset creation
* Data visualization
* Linear Regression model training
* Model evaluation using **MAE, MSE, and R2 Score**
* User input prediction

## Files Included

* `Day12_Project_Improvement.ipynb`
* `dataset.csv`
* `README.md`
* `screenshot.png`

A professional machine learning mini project organized and published on GitHub.
